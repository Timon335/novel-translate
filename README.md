# 📖 แปลนิยายอังกฤษ → ไทย (รันในเครื่องตัวเอง)

คู่มือนี้เขียนสำหรับคนที่ไม่มีพื้นฐานสร้างเว็บมาก่อน ทำตามทีละขั้นได้เลย

---

## ขั้นตอนที่ 1: ติดตั้ง Node.js (ทำครั้งเดียว)

1. เข้า https://nodejs.org
2. ดาวน์โหลดเวอร์ชัน **LTS** (ปุ่มซ้ายมือ)
3. ติดตั้งแบบ Next > Next > Finish ตามปกติ
4. เช็คว่าติดตั้งสำเร็จ เปิด Command Prompt (หรือ PowerShell) แล้วพิมพ์:
   ```
   node -v
   ```
   ถ้าขึ้นเลขเวอร์ชัน (เช่น v20.11.0) แปลว่าใช้ได้

---

## ขั้นตอนที่ 2: ขอ API Key ฟรีจาก Google (ทำครั้งเดียว)

1. เข้า https://aistudio.google.com/apikey
2. ล็อกอินด้วย Gmail
3. กด **Create API key**
4. คัดลอกรหัสที่ได้เก็บไว้ (รูปแบบจะขึ้นต้นด้วย `AIza...`) — **ห้ามส่งรหัสนี้ให้ใครดู**

---

## ขั้นตอนที่ 3: เตรียมไฟล์โปรเจกต์

1. แตกไฟล์ zip ที่ได้ไปไว้ที่ Desktop เช่น `Desktop\novel-translator`
2. เปิด Command Prompt แล้วเข้าไปในโฟลเดอร์นั้น:
   ```
   cd Desktop\novel-translator
   ```
3. ติดตั้งของที่โปรเจกต์ต้องใช้ (รอสักครู่ครั้งแรก):
   ```
   npm install
   ```

---

## ขั้นตอนที่ 4: ใส่ API Key ของพี่

1. ในโฟลเดอร์โปรเจกต์ จะเห็นไฟล์ชื่อ `.env.example`
2. **คัดลอกไฟล์นี้แล้วเปลี่ยนชื่อเป็น `.env`** (ตัดคำว่า `.example` ออก)
3. เปิดไฟล์ `.env` ด้วย Notepad แล้วแก้บรรทัดแรกให้เป็นรหัสที่ได้จากขั้นตอนที่ 2 เช่น:
   ```
   GEMINI_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXX
   ```
4. บันทึกไฟล์

---

## ขั้นตอนที่ 5: รันเว็บ

ใน Command Prompt (อยู่ในโฟลเดอร์โปรเจกต์) พิมพ์:
```
npm start
```

จะเห็นข้อความ:
```
เปิดเบราว์เซอร์ไปที่ http://localhost:3000
```

เปิดเบราว์เซอร์ (Chrome แนะนำสุด เพราะรองรับเสียงพูดดีที่สุด) แล้วพิมพ์ที่อยู่:
```
http://localhost:3000
```

---

## วิธีใช้งาน

1. วางลิงก์หน้านิยาย (ภาษาอังกฤษ) ที่ช่อง input
2. กด "แปลนิยาย" รอสักครู่ (ยิ่งเรื่องยาว ยิ่งใช้เวลานาน)
3. อ่านแบบคู่ อังกฤษ-ไทย หรือกดสลับดูไทยอย่างเดียวก็ได้
4. กด "▶ อ่านออกเสียง" เพื่อฟังเสียงพูดภาษาไทย ปรับความเร็ว/เลือกเสียงได้จากแถบด้านล่าง

---

## ปัญหาที่อาจเจอ

- **"ยังไม่ได้ตั้งค่า GEMINI_API_KEY"** → กลับไปเช็คขั้นตอนที่ 4 ว่าเปลี่ยนชื่อไฟล์เป็น `.env` แล้วหรือยัง (ไม่ใช่ `.env.example`)
- **แปลช้ามาก** → ปกติ เพราะแปลทีละส่วนเรียงกันเพื่อรักษาความต่อเนื่องของเนื้อเรื่อง เรื่องยาวอาจใช้เวลาหลายนาที
- **ดึงเนื้อหาจากลิงก์ไม่ได้** → บางเว็บป้องกัน bot ไว้ หรือโครงสร้างหน้าเว็บไม่ตรงกับที่ระบบคาดไว้ ลองเว็บนิยายอื่น
- **ไม่มีเสียงไทยให้เลือก** → เครื่องบางเครื่องไม่มีเสียงไทยติดตั้งมาให้ ระบบจะใช้เสียงอื่นแทนแล้วอ่านทับศัพท์ไทยเป็นเสียงแปลกๆ (เป็นข้อจำกัดของ Web Speech API ไม่ใช่บั๊ก)
- **ปิด Command Prompt แล้วเว็บหาย** → ต้องเปิด Command Prompt รัน `npm start` ใหม่ทุกครั้งที่จะใช้งาน (เพราะรันในเครื่องตัวเอง ไม่ได้ deploy ออนไลน์)
